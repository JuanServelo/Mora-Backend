Mora — documentação da API

Os sete serviços do backend, num lugar só. Tudo passa pelo gateway (Traefik, porta 8087): o Try it out de cada rota chama o serviço por ele. Para as rotas protegidas, faça login em POST /api/auth/login (auth-api) e cole o token no botão Authorize. Os exemplos usam os dados do seed de desenvolvimento: condomínio Residencial Parque Verde.
